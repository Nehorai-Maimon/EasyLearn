# EasyLearn (איזי לֶרְן) 📚

פלטפורמה חינוכית למכירה, ניהול והורדה של דפי עבודה, מערכי שיעור ומארזי תוכן חינוכיים.

## Tech Stack
- **Frontend**: React (Vite), modern styling, RTL support.
- **Backend**: Node.js & Express.
- **Database & ORM**: PostgreSQL with Prisma ORM.
- **Testing**: Dedicated `__tests__` directory for each component/page and API route.

## User Roles
1. **Admin (`ADMIN`)**: ניהול תכנים, העלאת דפי עבודה, עדכון מחירים ומבצעים, ודשבורד נתוני שימוש.
2. **Customer (`CUSTOMER`)**: חיפוש וסינון דפי עבודה, תצוגה מקדימה מוגנת, ואזור אישי ("הדפים שלי").
